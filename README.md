# Siripuram Lavanya — Portfolio

A modern, responsive single-page developer portfolio showcasing data analytics projects, interactive dashboards, and statistical models.

**Live site**: https://portfolio-virid-three-74.vercel.app/

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

## Tech Stack
- **Framework & Build**: React 19, Vite
- **Styling**: Tailwind CSS 4
- **Animations & Effects**: Framer Motion, AOS, WebGL
- **Contact & Integration**: EmailJS

## Run Locally

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Environment Variables

Configure the following variables in a `.env.local` file in the project root:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
